# OROVA Instagram captions — future posts

Write for a custom home builder or remodeler reading on a phone, not for a content calendar. Make one specific observation, explain the implication in plain language, and ask one useful question or offer one clear next step. Rotate the actual offer: Meta ads that bring enquiries, qualification/follow-up that handles opted-in leads, or both. Never imply an AI caller creates demand by itself.

Format:

1. Two to four short paragraphs, separated by a real blank line (`\n\n`). Keep the opening direct; avoid formulaic hype, all-caps urgency, emoji piles, invented statistics, invented client stories, and “game-changing” AI language.
2. Put the CTA in its own short paragraph. Do not offer the Retell demo number while the inbound launch gate is on HOLD.
3. After the CTA, insert a blank line, then three to five relevant hashtags separated by ordinary spaces. Do not glue a hashtag to the CTA or dump a long hashtag wall.
4. Save the exact caption in each post's `CAPTION.txt`, or its cloud-readable draft artifact. The active publisher reads the **`OROVA IG Publish Queue`** tab in [OROVA IG Post Log](https://docs.google.com/spreadsheets/d/1qbimCfGxaFUQrgu0yrGdYCFVkXfyBCSZAjoq5pvGoAo/edit?gid=1787252397): reread the exact row's `caption` value in column F and confirm real paragraph breaks before `ready`. The retired Make data-store publisher is not the current caption source. Keep the row `draft` if queue, media or duplicate checks are unavailable; `ready` instructs publication. After a normal successful run, check the live Instagram caption.
5. For a locally produced Reel, run `python scripts/ig_reel_preflight.py PATH_TO_REEL.mp4 PATH_TO_CAPTION.txt --url PUBLIC_VIDEO_URL` before ready promotion. It checks the local MP4, audio stream, caption formatting and public URL. It cannot prove that narration is audible, that the queue retained the caption, or that Instagram accepted the upload. Listen to the full Reel, verify media/license rights, reread the active Sheet row and check the live post separately. A Work cloud run needs equivalent available media checks; an inaccessible local file or ChatCut tool leaves the Reel a draft. An `application/octet-stream` URL warning requires extra media verification.

Historical entry evidence: the September 23 browser path flattened paragraph breaks in the former Make queue. On September 24, explicit `Shift+Enter` twice preserved `<br><br>` after reload. Those tests describe the retired editor, not the current Sheets transport. A well-formatted source file alone still does not prove the saved or published caption.
