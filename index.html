MikeBot is the Google application name for Mark's private OROVA automation project. Its current Google-account authorization supports Nova's Drive backup and recovery tools.

OROVA works on Meta lead generation and consent-checked lead qualification. Nova supports internal operations. This information site is not a public signup service, a client-results claim or a client agreement.

Why it connects to Google

The Drive integration creates, lists and downloads application-accessible backup files, verifies recovery copies and supports restoring operational records. The currently documented account grant is drive.file: access to files created with or explicitly made accessible to the application, not unrestricted access to every file in the account.

Google authorization happens on Google's own pages. This website never requests a password, token or API key. MikeBot has two registered clients, hermesclaw-drive-backup and OROVA; their names do not create different privacy promises.

Understand the boundaries

Read the privacy notice for access, storage, operational processing, retention and deletion, and the use terms for authorized internal use.

The current Google-account grant does not include Gmail or Calendar access. Optional integrations in the source code are not proof of authorization. Additional account access or external-user use requires a separate review and accurate updated disclosures.
