## 6. Retell — both prompts rewritten

Both agents were offering a **free two-week pilot Mark never authorised**.
It did not originate in a prompt: it is baked into `business_context.json` in
six places, and that file contradicts itself —
`commercial_terms.first_client_pilot` says *$1,500-2,000/mo for 60 days* while
`outbound_script.the_pilot` says *free*. The same file bans "free" as a spam
trigger word at line 177.

**Both prompts now carry a hard rule: `YOU DO NOT MAKE OFFERS. AT ALL.`** No
price, no range, no ballpark, no trial, no pilot, no discount, never "free".
Money questions deflect to Mark.

Also added to the **outbound** prompt:
- **No-name path.** CSLB leads have no owner, so `{{name}}` arrives as the
  literal `"there"` and `{{full_name}}` empty. It would have said *"Hi, is
  there available?"*. Now it never asks for a person it cannot name.
- **The twenty-seven-second opener** — the strongest opener OROVA can honestly
  use (~11% vs a 2.3% baseline). The two higher-scoring openers in the data
  both manufacture false familiarity and are explicitly banned.
- **Barge-in handling** — stop talking the instant they speak.
- **Explicit tool triggers** — call `check_availability_cal` the moment a time
  preference is expressed, not "let me check" followed by more talking.
- **"How did you get my number?"** — answers honestly: the licence register is
  public. This will come up constantly on a registry-sourced list.
- Arizona timezone guard (the rest of the ICP is Pacific).

## 7. Corrections — claims that were wrong, and how they were caught

Recorded because the pattern matters more than the instances: **every one was
an inference from a name, a docstring, or a remembered fact, and every one was
caught by reading the actual code or running the actual thing.**

1. **"Use the service account for Drive."** Recommended twice, and it is wrong.
   Service accounts have **no Drive storage quota** and cannot own files —
   the upload fails `403 storageQuotaExceeded`. It came from a false docstring
   in `vault_skill.py` claiming backups "land in the service account's own
   Drive (its 15GB)". `worker.py:1310` had already recorded the truth. **The
   real root cause: the OAuth consent screen is External + Testing, and Google
   expires those refresh tokens after exactly 7 days.**
2. **"Sole owners can't afford the retainer."** Wrong. `BusinessType` is a tax
   filing status, not a size or revenue signal — a sole proprietorship can
   carry ten W-2 employees, and in construction incorporating is usually a
   liability decision. It also contradicts ADR-0012's own rule that the filter
   is a deal-size ratio, not affordability.
3. **"Set `TARGET_LOCATION=Washington`."** Wrong, and it was the exact mistake
   the vault already warns about — letting the tooling drive the targeting.
   The ICP is the whole West Coast; narrowing it to fit the one working API is
   backwards.
4. **"The API key rotation didn't take."** True when run, wrong minutes later.
   The error was using an unchanged build SHA as evidence no deploy happened —
   **an env-var change restarts the service without changing the build hash.**
5. **"5 found, 1 saved is lock contention."** Only partly. The bigger cause was
   the dedup index treating an empty email as an identity (#129).
