## 3. The one architectural lesson worth carrying forward

**The same bug was found in three separate subsystems this session, and it is
almost certainly still elsewhere in the codebase.**

> A safety gate is applied at *call sites* instead of at the *chokepoint every
> path converges on*. It looks correct — the gate exists, it is well documented,
> it has tests — and it protects one path out of five.

| subsystem | gated before | total paths |
|---|---|---|
| AI-voice calls (`trigger_retell_call`) | 1 | 5 |
| Cold email approval (`send_outreach`) | 1 | 5 |
| Price suppression | voice only | voice + email |

In every case one of the ungated paths was **`planner.py`, which exposes the
function to the LLM as a callable tool.** That is the decisive argument: an LLM
decides whether to invoke a tool, so *there is no call site to add a check to*.
Per-call-site gating cannot ever be complete while a tool path exists.

**The tests could not catch any of it**, because each test exercised the one
integration that already worked. A test that only covers the correct path cannot
fail when a different path is missing.

> [!tip] The check to run on any future gate
> `grep -rn "<the_gated_function>(" app/` — then ask of *every* hit, including
> dead code and the planner tool registry, "does this one pass the gate?"

## 4. What is genuinely unresolved

### 4a. Durability — the backup does not accumulate, and we do not know why

**Two deploys, two total losses: 45 → 1, then 19 → 1.** Drive OAuth is dead
(`invalid_grant`, third recurrence — the consent screen sits in *Testing*, which
expires tokens every 7 days by design). Sheets is the only remaining tier.

The contradiction, both observed in production:

```
[DURABILITY:hunt] Sheets: 5/5 leads synced      <- write reports success
Restored 1/4 leads from Google Sheets           <- next boot finds 4 rows
```

**19 leads existed; the sheet holds 4, three of them `Acme` test fixtures.**
Static analysis cleared both code paths — same workbook, same `Leads` tab, and
the write deliberately matches on URL/business name rather than the resettable
SQLite id. So the code does not explain it.

**#153 deployed the instrument rather than a guess.** The next hunt logs either

```
✅ verified: sheet holds N rows for N leads
🚨 BACKUP INCOMPLETE — the database holds 19 leads but the Leads sheet has only 4 rows
```

which distinguishes **"the write is lying"** from **"the read looks in the wrong
place."** Those need opposite fixes. The restore-side half already works — the
thin-backup warning fired correctly on the 08-08 deploy.

**Owner action that actually resolves it either way: publish the Drive OAuth
consent screen.** Re-issuing the token alone has failed three times.

## 5. Research findings (external, verified)

- **Hermes Agent** — real: `NousResearch/hermes-agent`, **227,275 stars, 44,488
  forks**, MIT, pushed 2026-08-08. Verified via the GitHub API after the number
  looked implausible; it is correct. The applicable idea is **GEPA**
  ([arXiv:2507.19457](https://arxiv.org/abs/2507.19457)): rewrite a failing
  strategy using its failure rationale as feedback, rather than retiring it.
  **Do not build this yet** — it needs outcome data, and there are 0 outcomes.
- **OpenClaw** — real (`openclaw` org, 87 repos; `cloudflare/moltworker`, 9,930
  stars). **Adopt nothing.** Its core pattern — a chat-gated agent with machine
  control and human approval — is what `skill_forge.py` already is.
- **Free lead sourcing** — Utah CBR is the only US registry found with any email
  field, and it is *voluntary*. Florida DBPR has no phone/email. **The verified-
  email gap is structural, not a research failure.** No public registry publishes
  business emails.
- **Free business email: no.** Not "weak" — blocked by policy before
  deliverability is even a question. Zoho's free tier explicitly prohibits cold
  outreach (a 9th provider confirmed, matching the 8 already tested). Freenom shut
  down in 2024, so free domains are gone. Authenticated+warmed ≈ 87% inbox vs
  **≈12% cold/unauthenticated**, and Gmail hard-rejects unauthenticated bulk
  senders since Nov 2025. **Spend nothing here.**
