## 2. Corrections this session — the pattern matters more than the instances

Every one came from running something, and three overturned claims made
earlier in the very same session.

1. **"AI cold calling is unlawful."** WRONG — too broad, and Mark caught it.
   §227(b)(1)(B) reaches only a **residential** line, so a *verified business
   landline* is outside it. §227(b)(1)(A)(iii) is the separate clause covering
   **cellular** and **called-party-charged** services. The rule is
   **line-type dependent**, not blanket consent.
2. **Toll-free is the WORST AI-call target, not the safest** — (A)(iii) covers
   services where the called party is charged.
3. **"We own orova.co."** WRONG. It sits on a parking/for-sale lander
   (`parity.domains`). **`orova.io` is ours** — Cloudflare NS, completely blank.
4. **The opt-out gate looked broken and wasn't.** Suppression only records when
   `intent == COLD`, which looked like a legal obligation behind an LLM. The
   keyword classifier reads the *same* list and short-circuits first. Tested 10
   adversarial replies — 0 dropped. Verified rather than "fixed".
5. **Free domain-guessing for websites**: 87% "resolved", **7% correct**.

## 3. The phone lane — the real blocker

The lane **runs and is healthy** up to the gate: 23 leads queued, all
`awaiting approval`, `0 call(s) placed`.

**Booking is broken in three places** (verified live):
1. The outbound Retell LLM has **no `general_tools` field at all**, while its
   prompt instructs `CALL check_availability_cal`. The tools don't exist.
2. **No endpoint** for them to call — `cal_booking.py` only *receives* webhooks.
3. **No Cal.com API key** anywhere in the environment.

**The blocker is not legality — it is that line type is unknowable for free.**
`phonenumbers` returns `FIXED_OR_MOBILE` for every US geographic number;
portability killed prefix inference. Of the 23 queued: **20 unknown, 3
toll-free, 0 callable today**.

`app/core/call_consent.py` (#143) implements:

```
verified business LANDLINE  ->  lawful, NO consent required
CELL / TOLL-FREE / UNKNOWN  ->  consent required
```

**Shortest path to call #1: a carrier line-type lookup** (~half a cent per
number; 23 numbers is under a dollar). Any landline becomes callable
immediately with no consent and no DM. **Needs Mark's approval — it is a spend.**

## 4. Email — closed with evidence, do NOT reopen

`emailable=False` is **not** a config problem. `outreach_ready` never consults
`BUSINESS_POSTAL_ADDRESS`. Measured funnel:

| condition | measured |
|---|---|
| registry lead has a phone-verified website | **10%** |
| a business *with* a site publishes any email | **44%** |
| that email is direct, not a role inbox | **11%** |

**End to end ≈1%**, and the single "direct" hit was a departmental alias.
Small residential contractors do not publish personal email addresses.

CAN-SPAM needs **no prior consent** for B2B — the blockers are the missing
postal address ($ Mark can't spend) and ~no addresses to send to.
**#142 added the missing advertisement disclosure** (element 3 of 7).
