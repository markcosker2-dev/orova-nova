# Onboarding Checklist — Signed → Live

Run this the moment the agreement is signed and the invoice is paid.
Target: campaign live within **`[7]` days**.

## Day 0 — Access & Paperwork
- [ ] Agreement signed (both parties) + invoice paid — confirmed
- [ ] Onboarding call booked with `[CLIENT CONTACT]`
- [ ] **Meta Business Manager**: Client adds OROVA as **partner/admin** on the
      ad account (Business Settings → Partners → add by OROVA BM ID).
      🔴 Nothing runs until this succeeds — verify the same day.
- [ ] Client confirms **ad account is funded** (payment method on file at Meta)

## Day 1–2 — Assets & Intel
- [ ] Brand assets received: logo, colors, photos/video, brand guidelines
- [ ] Offer details: what they sell, price points, target customer, service area
- [ ] Landing page / lead form destination confirmed (or OROVA builds one)
- [ ] (P2) CRM access + booking-calendar access; Retell caller script tailored
- [ ] Pixel / conversions API check — is tracking installed & firing?

## Day 3–5 — Build
- [ ] Higgsfield ad creatives generated → **Client approves before publish**
      (always-approval gate — never publish or spend without sign-off)
- [ ] Campaign structured (audiences, budget, lead form) in the client account
- [ ] (P2) Retell qualification flow + booking wired; test call passes
- [ ] Nova outreach/lead handling pointed at the client workspace

## Day 5–7 — Go Live
- [ ] Client gives final go-live approval (ads + daily spend cap)
- [ ] Campaign live; first leads flowing → (P2) called & qualified in minutes
- [ ] Reporting cadence set (what Mark sends, how often)
- [ ] Week-1 check-in booked

## Standing gates (never bypass)
Publishing creatives, spending ad budget, and any change to spend are
**always Client-approved**. Escalate anything per [[escalation]].
